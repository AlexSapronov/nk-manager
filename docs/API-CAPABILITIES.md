# Возможности российского НК — исследование от 24.10.2026

## Статус доказательств

Точная версия API-документа **не получена**. Корпоративных доступов, API-ключей и сертификата нет. Реальных read-only ответов НК и пробных мутаций нет. Этап 0 завершён частично: подтверждены некоторые процессы ЛК и изучены доноры; интеграционные контракты остаются блокерами. Ни один API-метод не считается проверенным.

Открытие официального адреса [API НК](https://апи.национальный-каталог.рф/) через веб-инструмент вернуло ошибку доступности. [Общая инструкция](https://docs.crpt.ru/gismt/Инструкция_по_работе_в_НК/) не прочитана: инструмент сообщил превышение лимита 4 MiB. Это ограничения получения документов в данной среде, а не доказательство отсутствия API.

## Прочитанные первичные источники

- **S1**, «Массовая загрузка карточек товаров», обновление **24.09.2026**: [официальная статья](https://markirovka.ru/knowledge/tovarnyegruppy/obschie-voprosy-gis/massovaya-zagruzka-kartochek-tovarov-v-natsionalnyy-katalog). Описывает подтверждённый e-mail, активные группы и импорт через ЛК. Не является API-контрактом.
- **S2**, «Как массово выгрузить карточки», обновление **28.07.2026**: [официальная статья](https://markirovka.ru/knowledge/tovarnye-gruppy/obschie-voprosy-gis/kak-massovo-vygruzit-kartochki-s-natsionalnogo-kataloga). Подтверждает границы ручного XLSX-экспорта, а не API-лимиты.
- **S3**, «Для импортного товара уже есть иностранные GTIN», обновление **24.06.2026**: [официальная статья](https://markirovka.ru/knowledge/tovarnye-gruppy/obschie-voprosy-gis/dlya-importnogo-tovara-uzhe-est-inostrannye-gtin-mozhno-ikh-zagruzit-v-sistemu). Разрешённые группы и договорные права надо сверить для компании.
- **S4**, «Как отредактировать необязательные атрибуты», обновление **23.10.2026**: [официальная статья](https://markirovka.ru/knowledge/tovarnye-gruppy/obschie-voprosy-gis/kak-otredaktirovat-neobyazatelnye-atributy-kartochki-v-kataloge-markirovannykh-tovarov-dlya-vsekh-tg). Подтверждает двойную версию и необходимость повторной публикации. Упрощённые карточки имеют отдельные ограничения; автоматически заменять существующие черновики нельзя.

## Пакет для закрытия блокеров

Получить актуальный документ из ЛК → «Помощь» → «Общие инструкции» → «Описание методов API каталога», записать версию, дату и SHA-256. Нужны также схема радиоэлектроники, справочники, форматы ошибок/модерации, точная спецификация подписи и правила выделения GTIN.

Затем с разрешённым корпоративным доступом: безопасно прочитать список, одну опубликованную карточку и существующий черновик; сохранить обезличенные примеры без токенов и персональных данных. Для каждой строки матрицы зафиксировать method, URL, права, request/response и лимиты. Эксперимент с созданием, выделением GTIN или УКЭП — только после отдельного явного разрешения владельца на конкретный пилот.

Никаких предполагаемых `/create`, `/publish` или API Казахстана в реализации нет. Ссылки на ЛК могут быть добавлены только после проверки реального маршрута; вымышленные deep-link не используются.
