# Реализованные методы российского НК

Источник: [официальная документация](https://docs.crpt.ru/gismt/API_%D0%9D%D0%9A/), v5.68 от 28.09.2026. Клиент: `nk_manager/nk.py`. Авторизация — `apikey`; ключ пользователя вводится в админке. Подтверждение контракта документацией и синтетическими тестами не доказывает права организации или работу оборудования.

| Возможность | Метод | Подтверждение в приложении |
|---|---|---|
| Каталог всех доступных статусов | GET /v4/product-list | Явные даты, limit/offset, деление диапазона при 413 |
| Полные карточки | GET /v3/feed-product | good_ids до 25, сохранение good_id/сырых снимков |
| Категории и атрибуты | GET /v3/categories, /v3/attributes | Реальные cat_id/attr_id, типы, обязательность, встроенные справочники |
| Создать/обновить | POST /v3/feed | Существующий good_id обязателен при обновлении |
| Результат feed | GET /v3/feed-status | Затем сверка фактических полей чтением карточки |
| Модерация | GET /v3/feed-moderation | Изменяющий GET, очередь без слепого повтора |
| Выделение GTIN | GET /v3/generate-gtins | Отдельное подтверждение, quantity=1 |
| XML для подписи | POST /v3/feed-product-document | Точные UTF-8 байты, SHA-256, lease подписанта |
| Публикация | POST /v3/feed-product-sign-pkcs | detached CMS; далее published + good_signed |

Рабочий URL: `https://апи.национальный-каталог.рф`; sandbox: `https://api.nk.sandbox.crptech.ru`. 429 и Retry-After учитываются; неопределённый результат изменяющей операции требует сверки. Размер партии XML/sign в приложении — одна карточка, в пределах документированного максимума 10.

Windows-протокол адаптирован из [marking-bm](https://github.com/AlexSapronov/marking-bm), commit ce77a1cf720ff62530988b091c29c2dc0ae69ed6. Используется CAdESCOM через VBS с локальной проверкой подписи. Реальные ключ, API-ответы организации и Рутокен в среду разработки не передавались.

Ограничения комплектов, зависимых справочников и пилота перечислены в [инструкции](NK-LIVE.md). Предыдущее исследование о недоступности контракта устарело: документ найден и прочитан.
