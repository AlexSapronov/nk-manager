# Локальные предложения шаблонов · формат 1

Этот формат относится к **точным именам полей исходной XLSX-выгрузки**, а не к официальным ID атрибутов API НК. Производственная схема и типы НК пока не загружены. Утверждение здесь означает применение для локальной подготовки.

```json
{
  "schema_version": 1,
  "name": "Название категории",
  "tnved": "8536901000",
  "category": "Точное значение из источника",
  "card_type": "Точное значение из источника",
  "rules": [
    {
      "attribute": "Точное имя колонки характеристики",
      "mode": "fill_if_empty",
      "value": "Проверенное общее значение",
      "comment": "Источник и обоснование"
    }
  ]
}
```

Это поясняющий пример: значения категории и характеристики надо взять из реального корпуса. Пустые `category`/`card_type` допустимы, только если они действительно отсутствуют в источнике; такой шаблон подходит только записям с такими же пустыми значениями.

Режимы: `fill_if_empty`, `suggest_only`, `required_input`, `never_autofill`. Автоматически применяется только первый, только для уже существующего пустого поля, при точном совпадении ТН ВЭД/категории/типа. Остальные сохраняются в предложении для анализа, автоматической вставки не выполняют. Формулы `derived_from_explicit_field` пока не поддерживаются и отклоняются.

Нельзя автоматически заполнять индивидуальные PN, GTIN, модели, мощности/напряжения, серийные номера, изображения и разрешительные документы. Проверка имён защищённых полей — дополнительная защита, не замена предметной проверки администратором. Незнакомый атрибут нельзя утвердить до появления в карточках соответствующей категории.

Импорт сохраняет предложение и новую версию. Только административная серверная сессия может активировать версию. Новая активная версия переводит прежнюю в неактивную; возврат активирует выбранную прежнюю версию, не перезаписывая уже заполненные карточки. Тело утверждённой версии неизменяемо.

Применение: выбрать карточки → «Применить шаблоны» → посмотреть изменения и совпадения → подтвердить. Перед записью проверяются актуальная ревизия, ответственность, архив и активная версия шаблона. Частичные результаты показываются отдельно. GTIN и внешний ID карточки не меняются.
