# nk-manager

Менеджер российского Национального каталога «Честного знака».

Реализация ведётся поэтапно: исследование API → согласование интерактивного UI/UX-прототипа → основное приложение. Первый этап поставляется отдельным pull request. Реальная интеграция и производственная готовность пока не заявляются.
